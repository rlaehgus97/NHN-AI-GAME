# 🚇 지옥철 생존기

퇴근길 지옥철에 탑승해 **45초**를 버티고 목적지에서 무사히 하차하는 3D 생존 프로토타입입니다.
Three.js로 제작했으며 별도 빌드 도구 없이 브라우저에서 바로 실행됩니다.

## 게임 소개

- 체력(❤)과 명예(⭐)를 관리하며 목적지 역까지 생존하는 것이 목표입니다.
- 서 있으면 체력이 서서히 닳고, 좌석에 앉거나 손잡이를 잡으면 소모량이 줄거나 회복됩니다.
- "만취 비틀이", "백팩 회전맨" 같은 민폐 승객(빌런)을 피하거나 가방으로 밀어내야 합니다.
- 자리 양보, 급정거 같은 랜덤/스크립트 이벤트가 발생하며 선택에 따라 명예가 오르내립니다.
- 제한 시간 안에 문으로 하차하지 못하거나 체력/명예가 바닥나면 게임 오버입니다.

## 조작법

| 키 | 동작 |
|---|---|
| `W A S D` | 이동 |
| `Shift` | 대시 |
| `Space` | 좌석 경쟁 연타 |
| `E` | 손잡이 잡기 / 좌석 앉기·일어서기 |
| `F` / 좌클릭 | 가방 휘두르기 |
| `1` / `2` | 이벤트 선택지 고르기 |

## 실행 방법

빌드 과정이 없는 순수 HTML/CSS/JS 프로젝트입니다. 아래 두 가지 방법 중 하나로 실행하세요.

```bash
# 로컬 서버로 실행 (권장 — 모듈 script 로드 시 CORS 문제 방지)
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

또는 `index.html`을 브라우저로 직접 더블클릭해서 열어도 대부분의 환경에서 동작합니다.

## 기술 스택

- HTML / CSS / Vanilla JavaScript (ES6, no build tools, no npm)
- [Three.js r128](https://threejs.org/) (UMD, CDN 로드)

## 폴더 구조

```
index.html          # 마크업, CSS/JS 연결
style.css            # 전체 UI 스타일
js/
  constants.js       # 밸런스 상수, 상태 enum, 차량 치수
  state.js            # 전역 변수 및 게임 진행 상태(G)
  scene.js            # Three.js 씬/환경/캐릭터 모델 생성
  entities.js         # NPC·빌런 스폰
  player.js           # 플레이어 이동, 상호작용, 가방 공격
  ai.js               # NPC 좌석 경쟁 AI, 빌런 AI
  systems.js          # 체력/명예, 이벤트 매니저, 스테이지 타이머
  ui.js               # HUD 업데이트
  main.js             # 상태 전환, 메인 루프, 입력, 부트스트랩
```
