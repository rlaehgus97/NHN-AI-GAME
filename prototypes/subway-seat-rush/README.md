# 🚇 지옥철 생존기

퇴근길 지하철에 올라타 좌석을 차지하고, 진상 승객을 상대하며, 제한 시간 안에 목적지에서 하차하는
3D 생존 프로토타입입니다. Three.js로 제작했으며 별도 빌드 도구 없이 브라우저에서 바로 실행됩니다.

## 게임 흐름

1. 승강장에서 대기 → 문이 열리고 탑승 → 좌석 경쟁(SPACE 연타)
2. 좌석은 10개, 경쟁 승객은 14명이라 항상 몇 명은 서서 출발
3. 이동 중 취객·백팩 진상 승객이 등장해 방해하거나 공격함
4. 체력(❤)과 명예(⭐)를 관리하며 버팀 — 서 있으면 체력이 계속 닳고, 앉으면 회복되지만 완전히 안전하진 않음
5. 진상 승객을 퇴치하거나 자리를 양보하면 다른 승객이 자리를 내주는 보상이 따라옴
6. 목적지 도착 시 일부 승객도 함께 하차 — 제한 시간 안에 문으로 나가야 클리어

## 조작법

| 입력 | 동작 |
|---|---|
| 바닥을 좌클릭한 채 마우스 이동 | 포인터 방향으로 이동 |
| 빈 좌석 좌클릭 | 좌석 앞으로 자동 이동 |
| `Shift` | 대시 |
| `Space` | 좌석 경쟁 중 연타 |
| `E` | 손잡이 잡기/놓기, 일어서기 |
| `F` / 진상 승객 좌클릭 | 가방 휘두르기(진상 승객 공격) |
| `P` | 핸드폰 열기/닫기(현재 통근 스트레스 40 이상) |
| `1` / `2` | 이벤트 선택지 고르기 |

## 핵심 시스템

- **좌석 경쟁**: 좌석마다 "플레이어 게이지"와 "그 좌석을 노리는 NPC 게이지"가 동시에 채워져, 먼저 100%에 도달하는 쪽이 차지합니다. SEAT_RUSH 구간뿐 아니라 이동 중에도, 빈 좌석이 생기면 서 있던 NPC가 알아서 쫓아와 경쟁이 붙습니다.
- **자세와 위험도**: 서 있음(체력 지속 감소) / 손잡이(감소 적음) / 착석(서서히 회복, 단 백팩 피격·급정거 피해는 일부 받음). 진상 승객이 근처에 있으면 자세와 무관하게 추가 위험이 붙습니다.
- **진상 승객 AI**: 취객은 불규칙하게 비틀거리며 주변 승객을 밀치고, 백팩 승객은 예고(TELEGRAPH) → 휘두르기(SWING) → 회복(RECOVERY) 순서로 공격해 타이밍 회피·반격이 가능합니다. 퇴치하지 않고 방치하면 명예가 주기적으로 깎입니다.
- **보상 좌석**: 진상 승객을 퇴치하거나(서 있을 때) 자리를 양보하면, 앉아있던 다른 승객 한 명이 실제로 일어나 자리를 비워주고 5초간 플레이어 전용으로 예약됩니다.
- **핸드폰 미니게임**: 현재 통근 스트레스가 40 이상일 때만 `P`로 핸드폰을 열 수 있습니다. 약 8~10초짜리 스테이지를 클리어하면 핸드폰 내부에 클리어 결과가 표시되고 스트레스가 20 회복됩니다. 회복 후 스트레스가 40 미만인 상태에서 핸드폰을 닫으면 다시 40 이상이 될 때까지 열 수 없습니다. 상사 문자 피하기(초록 연락 -2 / 빨간 업무 +2), 숫자 카드를 드래그해 각 행과 열에 1·2·3을 채우는 3×3 미니 스도쿠, 언더테일풍 하트 피하기를 선택할 수 있습니다. 퇴근 의지의 하트는 방향키/WASD로만 움직이며 게임 영역의 좌·우클릭, 드래그와 터치 입력은 차단됩니다. 핸드폰을 닫으면 진행 상태가 일시정지되고, 핸드폰을 보는 동안 열차·이벤트·빌런은 35% 속도로 계속 진행됩니다.

## 실행 방법

빌드 과정이 없는 순수 HTML/CSS/JS 프로젝트입니다. 신규 시스템은 ES Module을
사용하므로 로컬 서버 실행이 필수입니다.

```bash
# 로컬 서버로 실행 (권장 — 모듈 script 로드 시 CORS 문제 방지)
python3 -m http.server 8000
# 이후 브라우저에서 http://localhost:8000 접속
```

`file://`로 직접 열면 ES Module 보안 정책 때문에 실행되지 않습니다.

## 기술 스택

- HTML / CSS / Vanilla JavaScript (ES6, no build tools, no npm)
- [Three.js r128](https://threejs.org/) (UMD, CDN 로드)

## 폴더 구조

```
index.html          # 마크업, CSS/JS 연결
style.css            # 전체 UI 스타일
js/
  constants.js       # 밸런스 상수, 상태 enum, 차량 치수, 이벤트 발생 시간 범위
  state.js            # 전역 변수 및 게임 진행 상태(G) 초기화
  scene.js            # Three.js 씬/환경/좌석/캐릭터·빌런 모델(피벗 구조 포함) 생성
  entities.js         # NPC·빌런 스폰 (속도/점유속도 개체 편차 포함)
  player.js           # 마우스 이동, 좌석 자동 이동, 자세, 가방 공격(윈드업-스트라이크-리커버리), 넉백
  ai.js               # 좌석 경쟁/배회 NPC AI, 취객·백팩 빌런 AI, 하차 처리
  systems.js          # 체력/명예, 좌석 양보 보상, 랜덤 이벤트 스케줄, 좌석 예약
  ui.js               # HUD 업데이트, 중앙 메시지 대기열
  minigames.js        # 핸드폰 UI, 해금/일시정지, 3종 미니게임 상태와 진행
  main.js             # 상태 전환(승강장→탑승→경쟁→이동→도착), 메인 루프, 입력, 재시작
  modules/
    movement-system.js # NPC·빌런 공용 이동 인터페이스
    seat-competition.js# 교체 가능한 좌석 경쟁 전략
    station-system.js  # 역 도착 시 일시 상태 정리
    stage-config.js    # 스테이지 타임라인 데이터
    event-director.js  # 이벤트 슬롯 선택·실행 시점 관리
    runtime.js         # 모듈 조립 및 기존 코드 연결
```
